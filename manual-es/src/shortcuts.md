# Atajos de teclado

**Ayuda > Atajos de teclado**, o **F1**, abre la lista de la aplicación
con cada tecla a la que responde, ventana por ventana. Esta página es la
misma lista, para leerla o imprimirla.

Las tablas escriben **Ctrl**, como en Linux y Windows. En un Mac, lee
**⌘** donde dice Ctrl y **Opción** donde dice Alt; la lista de **F1**
escribe lo que use tu computadora.

## En cualquier lugar

Funcionan estés donde estés, salvo mientras escribes en un campo de
texto.

| Tecla | Qué hace |
|---|---|
| **Espacio** | Reproduce o detiene. En el rack de canales o el piano roll, reproduce o detiene el patrón. |
| **Inicio** | Va al inicio. |
| **Fin** | Va al final. |
| **RePág** / **AvPág** | Un compás atrás / adelante. |
| **L** | Cambia entre el modo patrón y el modo canción. |
| **F1** | Abre o cierra la lista de atajos. |

## Ventanas

Cada tecla muestra una ventana o un panel, o lo oculta.

| Tecla | Qué muestra |
|---|---|
| **F5** | Hoja de acordes |
| **F6** | Rack de canales |
| **F7** | Piano roll |
| **F8** | Teclas de armonía |
| **Alt+F8** | El panel Patrones y biblioteca |
| **F9** | Mezclador |

## Archivo y Edición

| Tecla | Qué hace |
|---|---|
| **Ctrl+N** | Nuevo |
| **Ctrl+O** | Abrir |
| **Ctrl+S** | Guardar |
| **Ctrl+Mayús+S** | Guardar como |
| **Ctrl+Q** | Salir |
| **Ctrl+Z** | Deshacer |
| **Ctrl+Mayús+Z** o **Ctrl+Y** | Rehacer |

## Zoom

Las teclas hacen zoom en lo que está bajo el puntero: la lista de
reproducción, el piano roll, el rack de canales, o toda la ventana en
cualquier otro lugar (ver [Deshacer, zoom, ventanas y
ajustes](settings.md#zoom)).

| Tecla | Qué hace |
|---|---|
| **Ctrl++** / **Ctrl+−** | Más ancho / más angosto |
| **Alt++** / **Alt+−** | Más alto / más bajo |
| **Ctrl+0** | Vuelve al 100% |
| **Ctrl**+rueda | Más ancho o más angosto |
| **Alt**+rueda | Más alto o más bajo |

En muchos teclados **=** comparte la tecla con **+**, así que **Ctrl+=**
y **Alt+=** también hacen zoom.

## Hoja de acordes

Funcionan después de hacer clic en un compás (ver [La hoja de
acordes](chord-sheet.md)).

| Tecla | Qué hace |
|---|---|
| **Flechas**, **Tab**, **Mayús+Tab** | Se mueven entre compases. Con **Mayús**, seleccionan los compases por los que pasas. |
| **Intro** o **F2** | Escribe en el compás. Empezar a escribir hace lo mismo. |
| **Supr** o **Retroceso** | Borra los compases seleccionados. |
| **Ctrl+A** | Selecciona todos los compases. |
| **Ctrl+C** | Copia los compases, como texto. |
| **Ctrl+X** | Corta los compases. |
| **Ctrl+V** | Pega compases, o un esquema de acordes entero. |
| **Esc** | Deselecciona todo. |

## Piano roll

Actúan sobre las notas seleccionadas, o sobre todas las del canal cuando
no hay ninguna seleccionada (ver [El piano roll](piano-roll.md)).

| Tecla | Qué hace |
|---|---|
| **↑** / **↓** | Sube / baja un semitono |
| **Mayús+↑** / **Mayús+↓** | Sube / baja una octava |
| **Alt+↑** / **Alt+↓** | Sube / baja una nota de la tonalidad |
| **←** / **→** | Un paso antes / después |
| **Mayús+←** / **Mayús+→** | Un pulso antes / después |
| **Ctrl+C** | Copiar |
| **Ctrl+X** | Cortar |
| **Ctrl+V** | Pegar |
| **Ctrl+D** | Duplicar |
| **Supr** o **Retroceso** | Eliminar |
| **Ctrl+A** | Selecciona todas las notas |
| **Esc** | Deselecciona todo |

## Lista de reproducción

Actúan sobre los clips seleccionados (ver [Los patrones y la lista de
reproducción](patterns-and-playlist.md)).

| Tecla | Qué hace |
|---|---|
| **Ctrl+C** | Copiar |
| **Ctrl+X** | Cortar |
| **Ctrl+V** | Pegar |
| **Ctrl+D** | Duplicar |
| **Supr** o **Retroceso** | Eliminar |
| **Ctrl+A** | Selecciona todos los clips |
| **Esc** | Deselecciona todo |

## Rack de canales

Funcionan después de hacer clic en el nombre de un canal (ver [El rack
de canales](channel-rack.md)).

| Tecla | Qué hace |
|---|---|
| **Supr** o **Retroceso** | Elimina el canal. |
| **Esc** | No selecciona ningún canal. |

## Teclas de armonía

| Tecla | Qué hace |
|---|---|
| **1** a **7** | Toca el acorde de cada grado de la tonalidad (ver [Las teclas de armonía](harmony-keys.md)). |

## Teclado del equipo

Tocan notas mientras **MIDI > Teclado del equipo como piano** está
activado (ver [Teclados y sintetizadores
MIDI](midi.md#el-teclado-del-equipo)).

| Teclas | Qué tocan |
|---|---|
| **Z X C V B N M** | Las teclas blancas desde Do4 |
| **S D G H J** | Las teclas negras desde Do♯4 |
| **Q W E R T Y U I O P** | Las teclas blancas desde Do5 |
| **2 3 5 6 7 9 0** | Las teclas negras desde Do♯5 |

## Editor de estilos

| Tecla | Qué hace |
|---|---|
| **Espacio** | Toca el estilo. |
| **Ctrl+S** | Guarda el estilo. |
| **Ctrl+Mayús+S** | Guarda el estilo como. |
| **Ctrl+Z** | Deshacer. |
| **Ctrl+Mayús+Z** o **Ctrl+Y** | Rehacer. |
| **Esc** | No selecciona ningún canal. |

El editor de estilos tiene su propio deshacer, aparte del de la canción
(ver [Tus propios estilos](style-editor.md)).

## Con el ratón

| Dónde | Qué | Qué hace |
|---|---|---|
| Hoja de acordes | clic en un compás, luego **Mayús+clic** en otro | selecciona los compases entre ellos |
| Lista de reproducción | **Ctrl+clic** en clips | los suma a la selección |
| Lista de reproducción | **Ctrl+arrastrar** en un lugar vacío | selecciona los clips del recuadro |
| Lista de reproducción | clic derecho en un clip | lo elimina |
| Piano roll | **Ctrl+clic** en una nota | la suma a la selección, o la quita |
| Piano roll | **Ctrl+arrastrar** en un lugar vacío | selecciona las notas del recuadro |
| Piano roll | clic derecho en una nota, o arrastrar con el botón derecho sobre notas | las elimina |
| Biblioteca | **Ctrl+clic** en un estilo | lo aplica enseguida |
| Hoja de acordes, números de compás, nombres de pistas y canales, estilos | clic derecho | abre su menú |
