# El índice al final del PDF del manual (lo hace book-es/print-pdf.py).
#
# Cada palabra del glosario musical está en el índice, con la página a la
# que lleva su enlace «Se explica en», en negrita, y cada página donde un
# capítulo la presenta en negrita. Este archivo añade el resto: las partes
# de la aplicación y algunas palabras más, cada una con los capítulos que
# la explican.
#
#     Palabra: capitulo.md, capitulo.md#seccion, ...
#
# Un lugar es un capítulo como lo nombra SUMMARY.md, o una de sus
# secciones por el id de su título.
#
#     Palabra: véase Otra palabra
#
# envía al lector a otra entrada, y
#
#     Palabra: no capitulo.md
#
# deja fuera las negritas de ese capítulo, donde la palabra nombra otra
# cosa (un menú, un patrón).
