# Keyboard shortcuts

**Help > Keyboard shortcuts**, or **F1**, opens the app's own list of
every key it answers to, window by window. This page is the same list,
to read or print.

The tables write **Ctrl**, as on Linux and Windows. On a Mac, read
**⌘** for Ctrl and **Option** for Alt; the **F1** list writes whichever
your computer uses.

## Anywhere

These work wherever you are, except while you are typing in a text box.

| Key | What it does |
|---|---|
| **Space** | Play or stop. In the channel rack or the piano roll, it plays or stops the pattern. |
| **Home** | Go to the start. |
| **End** | Go to the end. |
| **PageUp** / **PageDown** | Back / forward one bar. |
| **L** | Switch between pattern mode and song mode. |
| **F1** | Open or close the list of shortcuts. |

## Windows

Each key shows a window or a panel, or hides it.

| Key | What it shows |
|---|---|
| **F5** | Chord sheet |
| **F6** | Channel rack |
| **F7** | Piano roll |
| **F8** | Harmony keys |
| **Alt+F8** | Patterns and Library panel |
| **F9** | Mixer |

## File and Edit

| Key | What it does |
|---|---|
| **Ctrl+N** | New |
| **Ctrl+O** | Open |
| **Ctrl+S** | Save |
| **Ctrl+Shift+S** | Save as |
| **Ctrl+Q** | Quit |
| **Ctrl+Z** | Undo |
| **Ctrl+Shift+Z** or **Ctrl+Y** | Redo |

## Zoom

The keys zoom what is under the pointer: the playlist, the piano roll,
the channel rack, or the whole window anywhere else (see [Undo, zoom,
windows and settings](settings.md#zoom)).

| Key | What it does |
|---|---|
| **Ctrl++** / **Ctrl+−** | Wider / narrower |
| **Alt++** / **Alt+−** | Taller / shorter |
| **Ctrl+0** | Back to 100% |
| **Ctrl**+wheel | Wider or narrower |
| **Alt**+wheel | Taller or shorter |

On most keyboards **=** is the **+** key without Shift, so **Ctrl+=**
and **Alt+=** zoom too.

## Chord sheet

These work after you click a bar (see [The chord sheet](chord-sheet.md)).

| Key | What it does |
|---|---|
| **Arrows**, **Tab**, **Shift+Tab** | Move between bars. With **Shift**, select the bars you pass. |
| **Enter** or **F2** | Type in the bar. Just starting to type does the same. |
| **Delete** or **Backspace** | Clear the selected bars. |
| **Ctrl+A** | Select every bar. |
| **Ctrl+C** | Copy the bars, as text. |
| **Ctrl+X** | Cut the bars. |
| **Ctrl+V** | Paste bars, or a whole chord chart. |
| **Escape** | Select nothing. |

## Piano roll

These act on the selected notes, or on all of the channel's notes when
none is selected (see [The piano roll](piano-roll.md)).

| Key | What it does |
|---|---|
| **↑** / **↓** | Up / down a semitone |
| **Shift+↑** / **Shift+↓** | Up / down an octave |
| **Alt+↑** / **Alt+↓** | Up / down a note of the key |
| **←** / **→** | A step earlier / later |
| **Shift+←** / **Shift+→** | A beat earlier / later |
| **Ctrl+C** | Copy |
| **Ctrl+X** | Cut |
| **Ctrl+V** | Paste |
| **Ctrl+D** | Duplicate |
| **Delete** or **Backspace** | Delete |
| **Ctrl+A** | Select every note |
| **Escape** | Select nothing |

## Playlist

These act on the selected clips (see [Patterns and the

| Key | What it does |
|---|---|
| **Ctrl+C** | Copy |
| **Ctrl+X** | Cut |
| **Ctrl+V** | Paste |
| **Ctrl+D** | Duplicate |
| **Delete** or **Backspace** | Delete |
| **Ctrl+A** | Select every clip |
| **Escape** | Select nothing |

## Channel rack

These work after you click a channel's name (see [The channel
rack](channel-rack.md)).

| Key | What it does |
|---|---|
| **Delete** or **Backspace** | Delete the channel. |
| **Escape** | Select no channel. |

## Harmony keys

| Key | What it does |
|---|---|
| **1** to **7** | Play the chord on each degree of the key (see [The harmony keys](harmony-keys.md)). |

## Typing keyboard

These play notes while **MIDI > Typing keyboard to piano** is on (see
[MIDI keyboards and synths](midi.md#the-computer-keyboard)).

| Keys | What they play |
|---|---|
| **Z X C V B N M** | The white keys from C4 |
| **S D G H J** | The black keys from C♯4 |
| **Q W E R T Y U I O P** | The white keys from C5 |
| **2 3 5 6 7 9 0** | The black keys from C♯5 |

## Style editor

| Key | What it does |
|---|---|
| **Space** | Play the style. |
| **Ctrl+S** | Save the style. |
| **Ctrl+Shift+S** | Save the style as. |
| **Ctrl+Z** | Undo. |
| **Ctrl+Shift+Z** or **Ctrl+Y** | Redo. |
| **Escape** | Select no channel. |

The style editor has its own undo, apart from the song's (see [Your own
styles](style-editor.md)).

## With the mouse

| Where | What | What it does |
|---|---|---|
| Chord sheet | click a bar, then **Shift+click** another | selects the bars between them |
| Playlist | **Ctrl+click** clips | adds them to the selection |
| Playlist | **Ctrl+drag** on an empty place | selects the clips in the box |
| Piano roll | **Ctrl+click** a note | adds it to the selection, or takes it out |
| Piano roll | **Ctrl+drag** on an empty place | selects the notes in the box |
| Playlist | right-click a clip | deletes it |
| Piano roll | right-click a note, or right-drag over notes | deletes them |
| Library | **Ctrl+click** a style | applies it at once |
| Chord sheet, bar numbers, track and channel names, styles | right-click | opens their menu |
