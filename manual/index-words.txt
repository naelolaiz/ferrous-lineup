# The index at the back of the manual's PDF (book/print-pdf.py makes it).
#
# Every word of the music glossary is in the index, with the page its
# "Explained in" link goes to, in bold, and every page where a chapter
# introduces it in bold. This file adds the rest: the app's parts and a
# few more words, each with the chapters that explain it.
#
#     Word: chapter.md, chapter.md#section, ...
#
# A place is a chapter as SUMMARY.md names it, or one of its sections by
# the id of its heading.
#
#     Word: see Another word
#
# sends the reader to another entry, and
#
#     Word: not chapter.md
#
# leaves out that chapter's bold words, where the word names something
# else (a menu, a pattern).
